# CleanFlow

**[English](#english) · [Українська](#українська) · [Русский](#русский)**

---

## English

**Portfolio Project**

CleanFlow is a website for a home cleaning service. It is designed to present available cleaning packages, allow visitors to calculate an instant preliminary price based on the number of rooms and extra services, and conveniently submit a booking request online.

🔗 **Live Demo:** [https://webbit-ro.github.io/CleanFlow/](#)

## Українська

**Проєкт для портфоліо**

CleanFlow — це сайт для клінінгової компанії (сервісу прибирання житла). Він створений для того, щоб ознайомити клієнтів із видами прибирання, дати можливість миттєво розрахувати орієнтовну вартість залежно від кількості кімнат і додаткових послуг, а також зручно залишити заявку на прибирання онлайн.

🔗 **Демо сайту:** [https://webbit-ro.github.io/CleanFlow/](#)

## Русский

**Проект для портфолио**

CleanFlow — это сайт для клининговой компании (сервиса уборки жилья). Он создан для того, чтобы познакомить клиентов с видами уборки, дать возможность мгновенно рассчитать предварительную стоимость в зависимости от количества комнат и дополнительных услуг, а также удобно оставить заявку на уборку онлайн.

🔗 **Демо сайта:** [https://webbit-ro.github.io/CleanFlow/](#)
